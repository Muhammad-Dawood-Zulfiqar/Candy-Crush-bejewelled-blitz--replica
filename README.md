# Bejeweled Blitz Desktop

## 📖 Description
Bejeweled Blitz Desktop is a classic match-three puzzle game brought to the desktop environment. Enjoy the fast-paced and exciting gameplay of Bejeweled Blitz on your computer, with vibrant graphics and special gems.

## ✨ Features
* **Classic Bejeweled Gameplay:** Experience the iconic match-three gameplay with colorful gems.
* **Time-limited Rounds:** Enjoy fast-paced rounds with a time constraint to keep the excitement high.
* **Special Gems:** Encounter and strategically use special gems to boost your score.
* **Desktop Experience:** Play Bejeweled Blitz directly on your desktop for a convenient and immersive gaming experience.

## 🛠️ Dependencies
Ensure you have C++ runtime libraries and **SFML 2.6.1 (64 bit)** installed, as well as the pictures of all gems and backgrounds on your system.

## 🚀 Build and Run
1. Open the project in Visual Studio.
2. Build and run the application.

## 🎮 Usage

### Launch the Application:
* Debug it in Visual Studio.

### Gameplay:
* Match three or more gems of the same color by swapping adjacent gems.
* Create special gems for bonus points.
* **Destroyer gem** is created by joining 5 gems in an L shape or in a row. It explodes by matching with two gems of the same type and removes the row as well as column in which it is present.
* **Bomb gem** is made by joining 4 gems in either a row or a column. It explodes when combined with two gems of the same type and removes 8 gems that are adjacent in horizontal, vertical, as well as diagonal directions.

### Controls:
* Use the **Left, Right, Up, and Down arrow keys** to move the cursor.
* Press **Enter** to select a gem.
* Press **Enter** again at the distance of only 1 gem in the vertical or horizontal directions (diagonal distances are not applicable) to swap. This only works if there are at least three matching gems at the newly swapped positions.
